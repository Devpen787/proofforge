# AI Tool Attribution

This project was built during the hackathon with human-directed AI assistance.

## Tools Used

- OpenAI ChatGPT / Codex for implementation assistance, code review, debugging,
  test writing, documentation drafting, and local verification.
- AI-assisted browser and coding workflows for UI inspection, refactoring, and
  demo preparation.

## Human Direction

The product concept, target users, submission strategy, prize selection, product
judgment, and final acceptance decisions were directed by the project owner.
AI tools were used as development assistants, not as autonomous project owners.

## AI-Assisted Areas

- Product documentation and journey refinement under `docs/`.
- React web screens and styling under `apps/web/`.
- Local runner, evidence, mission, storage, source, payment, policy, verifier,
  and project model packages under `apps/runner/` and `packages/`.
- Automated tests and smoke checks.
- Demo script, README, and submission preparation.

## Reused Materials

The implementation uses open-source libraries declared in `package.json`,
including React, Vite, TypeScript, Vitest, Playwright, Zod, and the official 0G
storage SDK. No proprietary starter kit is required to run the project.

## Spec And Planning Artifacts

Public product specs, journey docs, acceptance gates, roadmap docs, and research
summaries are included in `docs/`. Private chat transcripts, local credentials,
and internal process notes are not committed.
